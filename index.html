🎯 Arahan Aktiviti

Objektif: Murid dapat menyambungkan sensor ultrasonik HC-SR04 kepada Arduino Uno dan LED dengan betul.

  1. HC-SR04 VCC → Arduino 5V
  2. HC-SR04 GND → Arduino GND
  3. HC-SR04 TRIG → Arduino D9
  4. HC-SR04 ECHO → Arduino D10
  5. Arduino D3 → perintang 220Ω → anod (+) LED
  6. Katod (−) LED → Arduino GND
Petua: Klik titik terminal pada komponen untuk mula menyambung wayar.

📡 Uji Sensor Ultrasonik

Gerakkan jarak objek. Dalam simulasi ini, LED menyala apabila objek berada pada jarak 20 cm atau kurang.

45 cm

Status LED: PADAM

Sambungkan litar dengan betul dan tekan “Uji Sensor”.

💡 Maklumat Komponen

HC-SR04: Mengukur jarak objek menggunakan gelombang ultrasonik.

Arduino Uno: Memproses bacaan sensor dan mengawal output.

LED: Menunjukkan keadaan objek berdasarkan jarak yang ditetapkan.

Perintang 220Ω: Mengehadkan arus yang mengalir melalui LED.
